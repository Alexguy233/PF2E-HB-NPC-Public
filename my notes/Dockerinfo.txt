To Create the Image (currently set to port forward to 80 in the container):
docker build --pull --rm -f Dockerfile -t pf2npc:latest .

To start running the image as a container:
docker run -d -p 8080:80 pf2npc:latest

To stop running the container:
docker ps  //lists running containers
docker stop <ID>

docker rm -f <container_id_or_name> //both stops and removes container to clear disk space
